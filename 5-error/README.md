# 5. 경고/에러

플라즈마 절단 기능을 실행하는 중에 발생할 수 있는 주요 에러와 조치 방법을 설명합니다.

## 에러 목록

|구분|번호|에러명|내용|조치 방법|
|:--:|:--:|:--|:--|:--|
|에러|E1563|프로세스 ID 불일치|현재 플라즈마 절단기에 설정된 프로세스 ID와 절단 조건의 프로세스 ID가 일치하지 않습니다.|플라즈마 절단기의 프로세스 ID를 절단 조건과 동일하게 다시 설정하십시오.|
|에러|E1564|플라즈마 절단기 준비 대기|플라즈마 절단기가 시작 준비 상태가 아니어서 `plasma on` 명령을 실행할 수 없습니다.|프로세스 ID를 설정한 후 절단기의 '시작 준비 완료' 신호가 입력되는지 확인하십시오.|
|에러|E1565|플라즈마 절단기 프로세스 ID 미설정|플라즈마 절단기에 프로세스 ID가 설정되지 않았거나 설정값이 유효하지 않습니다.|플라즈마 절단기에 작업 조건에 맞는 프로세스 ID를 설정하십시오.|
|에러|E1566|플라즈마 절단기 EtherCAT 통신 불량|플라즈마 절단기 슬레이브를 찾을 수 없거나, 절단 조건을 전송하는 중 EtherCAT SDO 통신 오류가 발생했습니다.|EtherCAT 슬레이브 노드 설정, 케이블 연결 및 통신 상태를 점검한 후 다시 실행하십시오.|
|에러|E1567|하이퍼썸 절단기 내부 에러|하이퍼썸 절단기에서 내부 에러 신호가 입력되었습니다. 절단기가 전달한 상세 에러 번호가 `ErrCode`에 함께 표시됩니다.|표시된 `ErrCode`를 확인하고 하이퍼썸 절단기 매뉴얼에 따라 에러를 조치하십시오.|

<br>

{% hint style="info" %}
E1567의 `ErrCode`는 로봇 제어기에서 생성한 에러 번호가 아니라 플라즈마 절단기에서 전달된 상세 에러 번호입니다.
{% endhint %}
